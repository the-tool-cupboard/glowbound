# Stage bible note — Night Lantern

Night Lantern sits **beside** the 10-stage campaign. It does not replace Bound, Journey complete, or campaign unlocks.

The campaign remains Sleeping Woods → Castle Gate → Moonwell → Crystal Ascent → Ember Bridge → The Tower → Starfall → Hollow Crown → Night Orchard → The Bound (Lantern trial). Clearing The Bound still ends the journey: “The Bound is sealed. The lantern holds.”

Night Lantern reuses a chapter’s layout, twist, art, and bed as **today’s dream** — a 5-pattern daily run with stars and streak. It never advances `highestReached`, never unlocks chapters, and never deep-links into campaign mid-run.

See [NIGHT-LANTERN.md](./NIGHT-LANTERN.md).
